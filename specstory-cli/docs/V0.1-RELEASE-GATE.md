## Known limitations

- Launch correctness is tested through executable/provider fakes. The gate deliberately did not
  authenticate or start a live Codex session, which would create external interactive state.
- Raw reveal is intentionally process-memory-only but still places sensitive text on the user's
  terminal when explicitly requested; users should treat terminal scrollback and screen recording
  as outside the application's storage boundary.
- v0.1 supports Linux and WSL. macOS, native Windows, package-manager distribution, accounts, sync,
  collaboration, AI enrichment, and semantic search remain deferred.
- Inherited upstream packages and dependencies remain compiled and tested as an unreachable archive.

None of these limitations violates the v0.1 locked safety or product scope.
