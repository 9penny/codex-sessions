# 网页功能检查记录

检查日期：2026-09-09。范围：当前 `agent/project-web-browser` 工作区的网页功能、共享索引和现有 CLI 回归测试。

## 发现并修复

会话 JSONL 改名或移动后，如果文件大小和修改时间不变，网页增量扫描会跳过更新，索引继续指向不存在的旧路径，导致预览失败。

新增 `TestWebScanFollowsRenamedNativeFile`，先确认测试确实因旧路径残留而失败，再将原生路径加入网页扫描的新鲜度判断。修复后该测试及相邻索引测试通过。该变更不修改原生会话文件，不改变已有 TUI 隐藏规则。
