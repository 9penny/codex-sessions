# Codex Sessions v0.1.0

The first supported Codex Sessions release provides a local-only terminal browser for native
Codex CLI session history on Linux and WSL.

## Highlights

- Browse and search sessions across projects, including Chinese and English text.
- Preview redacted conversations without storing raw content in the derived SQLite index.
- Resume a selected session in its recorded directory or start a new Codex session.
- Hide background `subagent`, `exec`, and unknown-source sessions by default.
- Rebuild the disposable index incrementally or force a complete reparse.
- Install checksum-verified `amd64` and `arm64` release archives with `install.sh`.

## Privacy and scope

- Native `~/.codex/sessions` JSONL files remain authoritative and are never modified.
- The index excludes reasoning, tool arguments, and tool output.
- There is no login, sync, analytics, telemetry, version check, or other application-level
  outbound path.
- v0.1 supports Linux and WSL. macOS and Windows are not release targets yet.
