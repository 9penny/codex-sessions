# Codex Sessions v0.2.3

v0.2.3 makes optional AI enrichment project-aware.

## Changed

- `csessions enrich` now defaults to the project containing the current working directory.
- `csessions enrich --project PATH` explicitly selects the project containing that directory.
- `csessions enrich --all` explicitly selects the global indexed session library.
- `--all` and `--project` are mutually exclusive.
- Dry-run and live enrichment use the same project filter, applied before `--limit` and token
  budgets. The resolved scope is printed before live confirmation.

This prevents a command run inside one project from silently spending its bounded batch on newer
sessions from unrelated projects. Global enrichment remains available, but now requires an explicit
`--all` choice.

All existing redaction, confirmation, source-fingerprint, incremental-resume, and budget safeguards
remain unchanged.
