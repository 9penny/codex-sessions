# v0.2 synthetic model evaluation

Date: 2026-08-15

## Decision

Use `gpt-5.4-mini` as the v0.2 default. Keep the model configurable, including
`gpt-5.3-codex-spark` when a custom endpoint exposes it.

## Method

The configured private endpoint was queried for model identifiers without sending a prompt. It
exposed all three evaluated candidates. Each candidate then processed the same three short,
entirely synthetic conversations:

- English OAuth callback debugging
- Chinese substring search
- mixed Chinese/English SQLite reindexing

Requests used the v0.2 strict metadata JSON schema, `store: false`, no tools, and a 512-token output
ceiling. The evaluator checked schema validity, language preservation, and six expected concepts.
It printed only aggregate scores, latency, and API-reported token counts; generated prose was not
printed or stored.

## Results

| Model | Cases passed | Concept score | Input tokens | Output tokens | Total tokens | Duration |
|---|---:|---:|---:|---:|---:|---:|
| `gpt-5.3-codex-spark` | 3/3 | 6/6 | 368 | 1,543 | 1,911 | 11.12 s |
| `gpt-5.4-mini` | 3/3 | 6/6 | 1,256 | 202 | 1,458 | 6.35 s |
| `gpt-5.6-luna` | 2/3 | 5/6 | 1,256 | 196 | 1,452 | 7.33 s |

`gpt-5.4-mini` matched Spark's quality floor while completing faster and using fewer total tokens.
Its [official standard API price](https://developers.openai.com/api/docs/models/gpt-5.4-mini) at
evaluation time was $0.75 per million input tokens and $4.50 per million output tokens, making this
three-case run approximately $0.00185 at official list price. The private endpoint may bill
differently. No official public API documentation or pricing entry for `gpt-5.3-codex-spark` was
found, so Spark cannot be called cheaper without endpoint-level billing evidence.

## Reproduction

From `specstory-cli`, with private `CSESSIONS_OPENAI_*` environment variables set:

```bash
go run ./cmd/csessions-enrich-eval \
  --models gpt-5.3-codex-spark,gpt-5.4-mini,gpt-5.6-luna
```

The evaluator contains synthetic fixtures only. It must never be pointed at native session text.
