# Codex Sessions v0.2.1

v0.2 adds optional, bounded AI metadata without changing the local-only default workflow.

## Highlights

- `csessions enrich --dry-run` parses, filters, redacts, truncates, and reports aggregate input
  size without an API request or metadata write.
- `csessions enrich --yes` generates a short title, summary, and bounded tags through an explicit
  Responses-compatible API request using `store: false`, no tools, and strict structured output.
- `gpt-5.4-mini` is the evidence-based default; `--model` keeps account-specific alternatives such
  as `gpt-5.3-codex-spark` selectable.
- Successful rows resume incrementally by native source fingerprint and prompt version. `--limit`,
  per-session input, total input, and output ceilings bound a run; `--force` regenerates.
- Current generated titles, summaries, and tags improve English and Chinese search. Lists,
  snippets, and masked preview mark them with `✦` and explain that generated metadata may be wrong.
- Stale metadata stops displaying and matching immediately after the native source changes.

## Privacy model

Normal resume, search, reindex, TUI, version, help, and enrichment dry-run paths remain network-free.
Live enrichment structurally removes reasoning, tools, tool arguments/output, record metadata, and
known session/path identifiers before fail-closed secret redaction. Native Codex JSONL is read-only.

Only validated generated metadata, aggregate usage, model/prompt versions, time, and source
fingerprint are stored in the disposable XDG SQLite database. Outbound conversation text and API
credentials are not persisted there. API-provider abuse-monitoring retention may still apply even
with `store: false`; live use therefore requires `--yes`.

See [the enrichment guide](V0.2-ENRICHMENT.md), [model evaluation](V0.2-MODEL-EVALUATION.md), and
[release gate](V0.2-RELEASE-GATE.md) for configuration and evidence.

## Support boundary

v0.2 remains a personal Linux/WSL-first project focused on Codex CLI. Embeddings, semantic search,
automatic/background enrichment, accounts, sync, collaboration, macOS, native Windows, and
package-manager distribution remain out of scope.
