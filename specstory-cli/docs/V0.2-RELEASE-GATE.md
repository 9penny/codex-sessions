## Known limitations

- `store: false` disables Responses application-state storage but cannot override an API provider's
  abuse-monitoring retention policy.
- Secret detection is fail-closed but no detector can promise perfect classification; users should
  inspect dry-run aggregates, keep batches bounded, and choose their endpoint deliberately.
- Generated metadata can be wrong. It is visibly marked and never replaces native JSONL or raw
  preview.
- v0.2 supports Linux and WSL. Embeddings, semantic search, background enrichment, macOS, native
  Windows, accounts, sync, collaboration, and package-manager distribution remain deferred.
- Inherited non-Codex source remains compiled and tested as unreachable reference material.

None of these limitations violates the locked v0.2 scope.
