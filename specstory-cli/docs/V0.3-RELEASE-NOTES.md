# Codex Sessions v0.3.0

v0.3.0 makes the disposable csessions index follow sessions permanently deleted by Codex.

## Changed

- A complete successful `csessions reindex` removes live derived rows whose native Codex sessions
  no longer exist.
- Related full-text search rows and optional AI metadata are removed in the same SQLite
  transaction.
- Provider load failures, enumeration errors or panics, individual session scan failures, and
  interrupted runs never use missing rows as deletion evidence.
- Valid partial scan results may still refresh existing sessions without triggering cleanup.
- csessions soft-delete tombstones remain preserved and continue to block reindex resurrection.
- Local-only TUI footers now advertise the available `d delete` and `p filter projects` keys.
- Documentation now distinguishes Codex `/delete`, which permanently removes the native saved
  session, from csessions `d`, which only hides derived local index data.

Native Codex JSONL remains authoritative and is never changed by csessions. AI enrichment behavior,
budgets, redaction, and network boundaries are unchanged in this release.
